# 30 days of coding 👩🏻‍💻

A place where all `"30 days of [your favorite programming language]"` resources are listed.

## Motivation 📈

There are lot of different learning repos with similar pattern: do coding in this particular programming language for 30-50-100 days. I find this kind of learning fascinating cause it creates a good habit in you routine, but for some reason I didn't find, where all these resources are gathered in one place, so I decided to do it myself.

## How do I decide to include a resource to the list? 🤔

- **It must be useful**: you should be able to learn from it.
- **It must be free**: you should not pay for it.
- **It must be relevant**: programming languages are evolving, so it should be up to date or at least still relevant.
